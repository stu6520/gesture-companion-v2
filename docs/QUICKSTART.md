# Gesture Companion v2.0.0 - Quick Start

## Start

1. Extract the entire ZIP to a folder. Do not run it from inside the ZIP.
2. Keep `GestureCompanion.exe`, `icon.ico`, and the `Bridge` folder together.
3. Double-click `GestureCompanion.exe`.
4. Open PaintTool SAI 1 or PaintTool SAI 2 and focus the canvas.

Gesture Companion runs in the Windows system tray and connects to the active SAI version automatically. There is no main window.

## Default gestures

- Pinch open: `PageUp`
- Pinch close: `PageDown`
- Rotate clockwise: `Shift+PageDown`
- Rotate counter-clockwise: `Shift+PageUp`
- Two-finger drag: `Space` + left-button drag
- One-finger slide: Pan
- One-finger press and hold: Right-click
- Two-finger tap: `Ctrl+Z`
- Three-finger tap: `Ctrl+Y`
- Four-finger tap: `Home`

## Settings and exit

- Double-click the tray icon to open Settings.
- Right-click the tray icon for Settings, Start with Windows, or Quit.
- Click Apply in Settings to save changes.
- Clear a hotkey field to disable that keyboard mapping.

Sensitivity controls how much finger movement is needed. Speed controls how quickly zoom or rotate actions repeat.

## If gestures do not work

1. Confirm the tray icon is running.
2. Make SAI the foreground application.
3. Confirm the complete `Bridge` folder is next to the EXE.
4. Check `%LOCALAPPDATA%\GestureCompanion\bridge.log`.

See `README.md` for customization and troubleshooting details.
